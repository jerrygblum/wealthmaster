# Success Metrics

## Product success

Primary: the owner no longer needs the legacy Excel workbook for ongoing finance tracking.

Supporting outcomes:
- current net worth is explainable and trusted;
- imported transaction history can be reconciled to source statements;
- expected/fixed costs are visible without spreadsheet cross-checks;
- portfolio value is calculated without external manual aggregation.

## Product quality metrics

As features exist, measure:
- import success rate;
- percentage of import rows needing manual correction;
- duplicate-candidate rate and confirmed-duplicate precision;
- automatic categorization acceptance/correction rate;
- number of uncategorized transactions;
- reconciliation success rate;
- number of stale price/FX inputs;
- missing expected transactions;
- failed import rows;
- backup/restore verification date.

Metrics should help improve product reliability, not create vanity dashboards.
